## Heart Disease Prediction - Machine Learning From Scratch

**[View rendered Notebook Here](https://alexpet2002.github.io/Heart_Disease_Prediction_using_machine_learning_from_scratch/)**

<br>This project includes core machine learning algorithms implemented from scratch in Python and applies them to a common domain: identifying the presence or absence of heart disease from patient characteristics.</br>

The aim is to explore both the mathematical foundations of machine learning and their practical application to real-world data.

### Project Objective

The primary objective is to investigate how different machine learning approaches can be used to identify patterns associated with the presence or absence of heart disease.

The project includes:

| Algorithm | Task | Key Concepts |
|---|---|---|
| **Principal Component Analysis (PCA)** | Dimensionality Reduction | Covariance matrix, eigendecomposition, feature projection |
| **Least Squares Classification** | Classification | Linear decision function, least-squares optimization |
| **Logistic Regression** | Classification | Sigmoid function, log-loss, gradient descent, decision boundary |
| **K-Nearest Neighbors (KNN)** | Classification | Distance metrics, nearest neighbors, majority voting |
| **Hybrid Naive Bayes** | Classification | Gaussian and categorical likelihoods, conditional probabilities |
| **Multilayer Perceptron (MLP)** | Classification | Forward propagation, activation functions, backpropagation, gradient descent |
| **K-Means** | Clustering | Centroid initialization, distance calculation, iterative optimization |

### Results 

| Algorithm | Test Accuracy | 
|---|---:|
| Least Squares Classification | 63.64 % |
| Logistic Regression | 86.67 % | 
| Hybrid Naive Bayes | 63.64 % | 
| K-Nearest Neighbors (KNN) | 84.44 % |
| Multilayer Perceptron (MLP) |  0.96% |
